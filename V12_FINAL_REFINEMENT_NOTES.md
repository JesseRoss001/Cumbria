# V12 Final Refinement Notes

This version is a refinement of the V11 site, not an unnecessary overhaul.

Implemented fixes:
- Tutor cards now use controlled 4:3 thumbnail crops, so faces are not cut off and images do not overtake the text area.
- Tutor card text is separated from the image area and uses safer line-height, wrapping and mobile spacing.
- WhatsApp remains a core contact gateway, but button wording is no longer repetitive across the site.
- The navbar script remains guarded against double initialisation.
- Mobile menu remains compact and one-column when open.
- The public website copy avoids internal prompt/keyword-war language.

Recommended route for parents:
Home → Start Here → Subject or Level Page → Tutor Profile/Prices → WhatsApp or Enquiry Form.
